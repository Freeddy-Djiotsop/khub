# KHub – Knowledge Hub

KHub ist eine einfache und zentrale Webseite, die wichtige Ressourcen unseres Werkes sammelt und organisiert.
Das Ziel ist es, wichtige Inhalte wie Links, Prädigungen, Dokumente und Bilder an einem Ort bereitzustellen,
damit Geschwister nicht mehr in langen Chatverläufen (z.B. WhatsApp) danach suchen müssen.

## Funktionen

Die Webseite enthält vier Hauptbereiche:

* **Nützliche Links** – wichtige Webseiten und Tools
* **Prädigungen** – hilfreiche Lernressourcen
* **Dokumente** – PDFs oder andere wichtige Dateien
* **Bilder** – Flyers

Die Navigation erfolgt über einfache Tabs, sodass Benutzer schnell zwischen den verschiedenen Kategorien wechseln können.

## Technologie

Das Projekt ist bewusst sehr einfach gehalten und verwendet nur grundlegende Webtechnologien:

* HTML
* CSS
* JavaScript

Es benötigt keine externe Bibliothek oder Framework.

## Hosting

Die Webseite wird kostenlos über **GitHub Pages** bereitgestellt.

Dadurch kann die Seite direkt aus dem Repository veröffentlicht und von allen Mitgliedern der Gruppe aufgerufen werden.


## Ziel des Projekts

KHub soll eine zentrale und leicht zugängliche Wissensplattform für uns alle sein, die das Teilen und Wiederfinden von wichtigen Informationen deutlich vereinfacht.
